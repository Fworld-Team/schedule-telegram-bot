# Токен на сервере

Создайте `telegram_bot_token.txt` с токеном BotFather одной строкой.
Этот файл исключён из Git и Docker-образа. Не вставляйте токен в README,
Issues, логи или GitHub Variables.

Контейнер работает от UID/GID 10001. В Linux файл должен быть доступен
ему для чтения: например, владелец серверный пользователь, группа 10001,
права 0640; каталог `secrets` на сервере доступен только его владельцу.
Инструкции: [SERVER_SETUP.md](../SERVER_SETUP.md).
