# Карточка расписания

В главном меню кнопка «Расписание» открывает «Сегодня», Пн–Пт и
«Интерактивное расписание». «Назад» в личном чате возвращает главную
клавиатуру. В группе подменю открывается кнопками в сообщении. Нажатие
«Назад» напоминает об основной клавиатуре и оставляет сообщение доступным
другим участникам. Фотографии берутся из существующего каталога.

## Данные

Дневная проверка скачивает страницу и PDF один раз за проход. Существующий
процесс разбора извлекает таблицы и возвращает обычные строки для уведомлений
и варианты недель для карточки. Варианты сохраняются в том же
`schedule_monitor/state.json`. Состояние старой версии заполнится после
следующей успешной дневной проверки. Если геометрия неоднозначна, кнопка
предлагает обычное расписание. При сетевой ошибке остаётся последний
принятый снимок.

Карточка берёт чётность из активного семестра с учётом ручной поправки.
Загруженная карточка переключает недели по московским понедельникам
локально. Группа и день хранятся на устройстве для конкретного сообщения.
Ручная правка, сделанная после публикации карточки, применяется при
следующем открытии новой карточки или при её обновлении вместе с расписанием.
Данные времени, занятий и кодов помещений берутся из PDF. Неоднозначные
коды помещений остаются в исходной строке занятия.

## Проверка на отдельном боте

Установите `BOT_SCHEDULE_WIDGETS=1` для тестового бота с отдельным каталогом
данных. После дневной проверки откройте «Интерактивное расписание» в
личном чате. Для неподдерживаемых клиентов к карточке добавляется подпись
с указанием обычных кнопок. Bot API 10.4 сейчас разрешает отправку таких
карточек в production только в личные чаты. PTB 22.8 вызывает методы
`sendWidget` и `editMessageWidgetData` через публичный `do_api_request`.

В SQLite хранится последняя запрошенная карточка на личный чат, исходные
данные её HTML и последняя попытка обновления. При изменении расписания
дневная проверка редактирует состояние карточки. Если состояние превышает
1024 байта или Telegram окончательно отклонил редактирование, бот отправляет
новую карточку без звука. При неоднозначном сетевом сбое повторной отправки
той же ревизии нет, чтобы избежать дубликатов. Обычная рассылка изменений
расписания использует прежние правила.

Офлайн-тесты используют два PDF Академии, подмену Telegram и тестовую
среду JavaScript. Прогон на настоящем тестовом боте нужен, чтобы проверить
рендер и хранение выбора в клиенте Telegram.
